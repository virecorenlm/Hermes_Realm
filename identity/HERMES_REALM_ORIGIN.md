# Hermes Realm Origin Pattern

Hermes Realm began as a private local-first experiment in giving a Hermes-based agent more continuity, voice, memory, and operational presence.

The public repository does **not** include the raw private origin archive. Instead, it preserves the reusable pattern:

- identity files as explicit runtime context,
- voice loop scripts,
- memory persistence examples,
- cron-compatible status pulses,
- systemd and environment templates,
- dashboard/monitoring documentation,
- modular workforce stubs.

If you build your own Realm, keep your private origin material in a private repository or local archive and publish only sanitized examples.
