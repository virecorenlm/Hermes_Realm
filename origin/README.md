# Origin Archive Placeholder

The original private project contains early phone, edge, and predecessor-system archives.
Those files are intentionally **not included** in the public template because they contain
personal identity material, private notes, local paths, and homelab-specific history.

Public users should treat this repository as a pattern library for building their own
Hermes continuity layer, not as a drop-in copy of someone else's private identity.

If you are adapting Hermes Realm:

1. Create your own identity files in `identity/`.
2. Keep private memories and raw exports outside Git.
3. Only publish sanitized examples, templates, and architecture notes.
