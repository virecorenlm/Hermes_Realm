# State graph pattern

Enumerate approved local roots and record nodes for scripts, skills, reports, and configured services. Add edges only when references are evidenced by source content or configuration. Mark missing paths and unavailable optional services clearly. Keep private filenames and raw content out of public exports. A companion graph generator is not included here.
