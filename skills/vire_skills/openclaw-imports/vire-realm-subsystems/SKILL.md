# Realm subsystem patterns

- Identity templates in `identity/` show how to keep inspectable continuity. Store real identity and memories privately.
- `workforce/` is a file-backed draft and status fleet with an offline smoke test.
- `scripts/` contains optional voice, memory, vision, queue, and integration examples.
- `cron-pulses/` contains experiments that should be reviewed before scheduling.
- State graphs, dashboards, tool routers, and MCP servers may be built as companion projects. They are not supplied or started by this checkout.

Configure service URLs and paths before using a subsystem. Do not infer that any service is installed merely because a skill mentions it.
